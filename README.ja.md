### 🛠 取り組んでいること

- React と TypeScript を使ったフロントエンド開発
- シェア、再訪、ディープリンクを通じたユーザーグロース
- 再利用可能な UI コンポーネントの開発と Web パフォーマンスの改善

### 🌱 興味・学習テーマ

- AI エージェント、コンテキストエンジニアリング、個人に寄り添うコンシューマー向けアプリ
- サーバーサイドレンダリングと Node.js によるフルスタック開発
- 日常のニーズを、小さく実用的な AI プロダクトにすること

### 🚀 構想・検討中のプロジェクト

- **Life RPG** — 日々の振り返りや人生の記録を、次の行動につながるクエストに結びつける AI アプリを構想中
- **Design to Code** — 再利用可能なコンポーネントを活用し、Figma のデザインからフロントエンドのページを生成する AI ワークフローを検討中
